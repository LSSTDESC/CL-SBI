----------------------------------------------------------------------
WHAT THE SCRIPT DOES (so the result is interpretable without rereading code)
----------------------------------------------------------------------
- Reuses the differentiable JAX NFW forward model + config from
  hierarchical_mcmc_poc (import hierarchical_mcmc_poc as H), but loads the
  high_rm_scatter obs set instead of the baseline.
- FREE model = the paper baseline: logM_j ~ Normal(mu_M, sig_M), free hyperparams.
  Hyperpriors match run_hier_all_experiments.make_model, so it reproduces the
  existing hier_post_obs_z1_lambda5_high_rm_scatter.pkl fit.
- INFORMED model: per-cluster logM_j drawn from a broad free Gaussian envelope
  (same free mu_M, sig_M) PLUS a numpyro.factor equal to the precomputed
  log-pdf of [Tinker08 dn/dlnM] x [McClintock18 richness-selection window for
  30<lambda<45], evaluated on a 1200-pt logM grid at z=0.275 with
  sigma_lnlambda = rm_scatter*ln10/F, F=1.356 (same convention as
  mcmcutils.logprior). The factor is wrapped as a differentiable jnp.interp.
  The RECOVERED population is read off as the latent per-cluster logM_j
  (deterministic site logM_pop), so it can be flat-topped/non-Gaussian even
  though the envelope is Gaussian.
- ONLY the mass population differs between the two models; concentration block
  (c0, beta, sig_c) and likelihood (sig_extra) are identical.
- Both run 4 chains x (1000 warmup + 1500 samples); r-hat checked < 1.05.

Design choice rationale: a numpyro.factor on the latent masses is the most
NUTS-robust way to inject the non-Gaussian physical shape (no discrete sampling,
no importance weights, fully differentiable), while still letting the data move
the population mean/width via the free envelope.
